# Synapse Marketing Agency

CREATE. CONNECT. GROW.

Digital marketing and web development agency website for Quetta, Balochistan.

## Publish on GitHub + Vercel (no Hostinger Node needed)

### 1. GitHub

1. Open [github.com](https://github.com) and sign in.
2. Click **New repository**.
3. Name it `synapse-website`. Keep it **Public** or Private.
4. Click **Create repository**.
5. Click **uploading an existing file**.
6. Extract this project folder on your computer.
7. Drag **all files from inside the folder** (package.json, src, public, vite.config.ts, …) into GitHub.
8. Click **Commit changes**.

### 2. Vercel

1. Open [vercel.com](https://vercel.com) and sign in with the **same GitHub** account.
2. **Add New… → Project**.
3. Import `synapse-website`.
4. Leave settings as they are. Vercel will run `npm install` and `npm run build`.
5. Click **Deploy**.
6. After it finishes you get a link like `https://synapse-website.vercel.app`.
7. **Settings → Domains** — add `synapsemarketing.pk` (or your domain from Hostinger).
8. In Hostinger DNS, add the two records Vercel shows (usually A `76.76.21.21` and CNAME `cname.vercel-dns.com`).

Hostinger is only used for the **domain**. The website itself runs on Vercel, so Node.js on Hostinger is not required.
